# CNN on CIFAR-10 – Lab 2 Worksheet

## Objective
This project implements a custom Convolutional Neural Network (CNN) trained on the CIFAR-10 dataset.
The goal is to analyze model training, computational complexity (FLOPs), gradient flow, and weight update dynamics,
with all experiments logged using Weights & Biases (WandB).

## Dataset
- CIFAR-10 (32×32 RGB images, 10 classes)
- Custom Dataset and DataLoader implemented using PyTorch

## Model
- Custom CNN architecture (not pretrained)
- Batch Normalization and ReLU activations
- Trained for 30 epochs

## Experiments
- FLOPs and parameter count analysis
- Training and validation performance logging
- Gradient flow visualization
- Weight update flow visualization

## Tools Used
- PyTorch
- Torchvision
- ptflops
- Weights & Biases (WandB)

## Notes
- Trained model weights are not uploaded as per instructions.
- All visualizations are available via WandB.
